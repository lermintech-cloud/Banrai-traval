# ระบบเบิกค่าเดินทางไปราชการ โรงเรียนบ้านไร่

เว็บแอปบน Cloudflare Pages + D1 (ฐานข้อมูลใหม่ ไม่เกี่ยวกับระบบลาเดิม) พิมพ์/PDF แบบ 8708 ทุกหน้ารวมเป็นแฟ้มเดียว

## ติดตั้ง
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub แล้วสร้างโปรเจกต์ใน Cloudflare Pages (Build command เว้นว่าง, Output directory = `/`)
2. สร้างฐานข้อมูลใหม่: Cloudflare → Storage & Databases → D1 → Create (ชื่อ เช่น `banrai-travel`)
   แล้วเปิด Console วางคำสั่งในไฟล์ `schema.sql` กด Execute  
   (หรือใช้ `npx wrangler d1 execute banrai-travel --remote --file=schema.sql`)
3. Pages → Settings → Bindings → Add → **D1 database** ชื่อตัวแปร **`DB`** เลือกฐานข้อมูลที่สร้าง → Redeploy
4. เปิดเว็บ → ตั้งค่า (รหัสเริ่มต้น `1234` เปลี่ยนทันที) → ใส่รายชื่อครู ผู้ลงนาม ลายเซ็น (ผอ./ธุรการ/การเงิน)

ไม่มี D1 ก็ลองใช้ได้ (เก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น)

## ขั้นตอนอนุมัติ
ครู → ธุรการ (ตรวจเอกสาร) → การเงิน (ตรวจยอด/เงินยืม) → ผู้อำนวยการ (อนุมัติ)

## แฟ้มเอกสาร (เรียงอัตโนมัติ แนวตั้ง/แนวนอนสลับเอง)
บันทึกขออนุมัติ → ประมาณการ → (หนังสือเชิญ/คำสั่ง แนบ) → แบบ 8708 ส่วนที่ 1 หน้า-หลัง → ส่วนที่ 2 (แนวนอน) → ใบเสร็จ (แนบ) → สัญญายืมเงิน (ถ้ามี) → อื่น ๆ
ถ้ามีหนังสืออนุมัติฉบับจริง ให้ติ๊ก "มีหนังสืออนุมัติฉบับจริงแนบแล้ว" แล้วแนบไฟล์แทน

## เงินยืม
กำหนดคืน = วันที่กลับถึง + 15 วัน มีนับถอยหลัง/เกินกำหนด การเงินกด "รับคืนเงินยืม" เมื่อคืนแล้ว

## ข้อควรทราบ
- ไฟล์แนบถูกแปลงเป็น JPEG เก็บใน D1 จำกัด ~1.9 MB ต่อแฟ้ม
- ฟอนต์ TH Sarabun New ฝังไว้ใน `css/fonts.css` แล้ว
- ตรวจอัตราเบี้ยเลี้ยง/ที่พักตามระเบียบก่อนกรอก (ระบบไม่ฝังอัตราตายตัว)
